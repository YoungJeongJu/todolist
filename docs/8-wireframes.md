### WF-01: 로그인 화면 (`/login`)

**연관 UC**: UC-02

#### 레이아웃

```
+------------------------------------------------------------------------------+
|                                                                              |
|                           TodoList                                           |
|                       개인 할 일 관리 서비스                                |
|                                                                              |
|              +------------------------------------------------+              |
|              |                                                |              |
|              |              로그인                           |              |
|              |                                                |              |
|              |  이메일                                        |              |
|              |  [____________________________________________]|              |
|              |                                                |              |
|              |  비밀번호                                      |              |
|              |  [____________________________________________]|              |
|              |                                                |              |
|              |  * 오류 상태:                                  |              |
|              |  +------------------------------------------+ |              |
|              |  | ! 이메일 또는 비밀번호가 올바르지 않습니다| |              |
|              |  +------------------------------------------+ |              |
|              |                                                |              |
|              |              [     로그인     ]               |              |
|              |                                                |              |
|              |        계정이 없으신가요? [회원가입]          |              |
|              |                                                |              |
|              +------------------------------------------------+              |
|                                                                              |
+------------------------------------------------------------------------------+
```

#### 컴포넌트 설명

| 컴포넌트        | 역할                                     | 연관 규칙              |
| --------------- | ---------------------------------------- | ---------------------- |
| 이메일 입력     | 로그인용 이메일 입력 필드                | UC-02 AC-01            |
| 비밀번호 입력   | 로그인용 비밀번호 입력 필드              | UC-02 AC-01            |
| 오류 메시지 박스 | 인증 실패 시 포괄적 오류 메시지 표시    | UC-02 AC-02, US-22     |
| 로그인 버튼     | 폼 제출, 인증 요청 트리거               | UC-02 AC-01            |
| 회원가입 링크   | `/register`로 이동                       | UC-01                  |

#### 주요 인터랙션

- 로그인 버튼 클릭 시 이메일·비밀번호 일치 여부 검증 후 메인 화면으로 이동 (UC-02 AC-01)
- 인증 실패 시 "이메일 또는 비밀번호가 올바르지 않습니다" 오류 메시지 표시, 이메일 존재 여부 미노출 (UC-02 AC-02, US-22)
- 미인증 상태에서 보호된 경로 접근 시 이 화면으로 리다이렉트 (UC-02 AC-03, US-20)
- 로그인 성공 시 저장된 themeMode 복원 후 메인 화면으로 이동 (UC-02 AC-04)

**연관 UC**: UC-01

```

|                                                                              |
|                           TodoList                                           |

|                                                                              |
|              +------------------------------------------------+              |
|              |                                                |              |
|              |              회원가입                         |              |
|              |                                                |              |
|              |  이름                                          |              |
|              |  [____________________________________________]|              |
|              |                                                |              |
|              |  이메일                                        |              |

|              |  * 오류 상태: ! 이미 사용 중인 이메일입니다   |              |
|              |                                                |              |
|              |  비밀번호                                      |              |
|              |  [____________________________________________]|              |

|              |                                                |              |
|              +------------------------------------------------+              |
|                                                                              |
+------------------------------------------------------------------------------+
```

#### 컴포넌트 설명

| 컴포넌트           | 역할                                          | 연관 규칙           |
| ------------------ | --------------------------------------------- | ------------------- |
| 이름 입력          | 사용자 이름 입력 (1~50자)                     | UC-01 AC-03         |
| 이메일 입력        | 가입용 이메일 입력 (이메일 형식, 중복 불가)   | UC-01 AC-01         |
| 이메일 오류 메시지 | 중복 이메일 또는 형식 오류 시 인라인 표시     | UC-01 AC-01, US-18  |
| 비밀번호 입력      | 비밀번호 입력 (최소 8자, 영문+숫자)           | UC-01 AC-02         |
| 비밀번호 오류 메시지 | 규칙 미충족 시 인라인 표시                  | UC-01 AC-02         |
| 비밀번호 확인 입력 | 비밀번호 재입력 일치 여부 확인               | -                   |
| 가입하기 버튼      | 폼 제출, 계정 생성 요청 트리거              | UC-01               |
| 로그인 링크        | `/login`으로 이동                             | UC-02               |

#### 주요 인터랙션

- 가입하기 버튼 클릭 시 이름(1~50자), 이메일(형식·중복), 비밀번호(8자 이상, 영문+숫자) 검증 (UC-01 AC-01~03)
- 각 필드 오류는 해당 필드 바로 아래 인라인으로 표시 (US-18)
- 가입 성공 시 '기본' 카테고리 자동 생성 후 즉시 로그인 상태로 메인 화면으로 이동 (UC-01 AC-04, AC-05)

### WF-03: 메인 화면 (`/`)

**연관 UC**: UC-07, UC-08, UC-09, UC-10, UC-11, UC-12

#### 레이아웃

```
+------------------------------------------------------------------------------+
|  TodoList                              [프로필]        [로그아웃]            |
+--------------------+---------------------------------------------------------+
|                    |                                                         |
|  카테고리          |  [미시작] [진행 중] [완료] [기한 초과]   [목록][캘린더]  |
|  ----------------  |                                                         |
|  > 전체            |  +-------------------------------------------------------+
|    기본            |  | [ ] 마케팅 보고서 작성         미시작 ▼  ~05/30  [수정][삭제] |
|    업무            |  +-------------------------------------------------------+
|    개인            |  | [ ] API 서버 구현              진행 중 ▼  ~06/01  [수정][삭제] |
|                    |  +-------------------------------------------------------+
|  ----------------  |  | [x] 디자인 시안 검토           완료    ▼  ~05/27  [수정][삭제] |
|  새 카테고리       |  +-------------------------------------------------------+
|  [______________]  |  | [ ] 주간 회의 준비             미시작 ▼  기한초과  [수정][삭제] |
|  [+추가]           |  +-------------------------------------------------------+
|                    |                                                         |
|                    |  * 빈 목록 상태:                                        |
|                    |  +-------------------------------------------+         |
|                    |  |  해당 조건에 맞는 할 일이 없습니다.       |         |
|                    |  |  [+ 할 일 추가] 버튼으로 등록해 보세요.  |         |
|                    |  +-------------------------------------------+         |
|                    |                                                         |
|                    |                              [+ 할 일 추가]            |
+--------------------+---------------------------------------------------------+
```

#### 컴포넌트 설명

| 컴포넌트              | 역할                                                | 연관 규칙                |
| --------------------- | --------------------------------------------------- | ------------------------ |
| 헤더 앱 타이틀        | 브랜드 식별, 메인 화면 링크                         | -                        |
| 헤더 프로필 링크      | `/profile`로 이동                                   | UC-03, UC-04             |
| 헤더 로그아웃 버튼    | 인증 토큰 제거 후 `/login`으로 이동                 | -                        |
| 카테고리 사이드바     | 카테고리 목록 표시, 선택 시 카테고리 필터 적용      | UC-12 AC-01              |
| 카테고리 항목 (기본)  | '기본' 카테고리, 삭제 버튼 없음                     | UC-06 AC-01, US-21       |
| 카테고리 항목 (일반)  | 사용자 정의 카테고리, 클릭 시 삭제 확인 절차 제공   | UC-06 AC-03              |
| 새 카테고리 입력      | 카테고리 이름 입력 (1~30자)                         | UC-05 AC-01              |
| 추가 버튼             | 카테고리 생성 요청 트리거                           | UC-05                    |
| 상태 필터 탭          | 미시작/진행 중/완료/기한 초과 탭, 선택 시 목록 재표시 | UC-11 AC-01~04         |
| 할 일 항목            | 제목, 상태 드롭다운, 기한, 수정/삭제 버튼           | UC-08, UC-09, UC-10      |
| 상태 드롭다운(▼)      | NOT_STARTED / IN_PROGRESS / DONE 직접 선택          | UC-10 AC-01, AC-02       |
| 빈 목록 안내          | 필터 조건에 해당하는 항목 없을 때 표시              | UC-11, US-11             |
| 뷰 전환 버튼 (목록/캘린더) | 우상단, 목록 뷰와 캘린더 뷰 전환. 캘린더 선택 시 월/주 토글 추가 표시 | UC-15 AC-01, AC-02 |
| FAB (+ 할 일 추가)    | 우하단 고정, 할 일 등록 모달 열기                   | UC-07                    |

#### 주요 인터랙션

- 카테고리 항목 클릭 시 해당 카테고리 필터 적용, 상태 필터와 동시 적용 가능 (UC-12 AC-01, AC-02)
- 상태 필터 탭 클릭 시 해당 상태 조건으로 목록 재표시 (UC-11 AC-01~04)
- 할 일 항목의 상태 드롭다운으로 상태 즉시 변경 (UC-10 AC-01, AC-02)
- 새 카테고리 이름 입력 후 [+추가] 클릭 시 카테고리 생성 (UC-05)
- 일반 카테고리 삭제 시 확인 절차 후 삭제, 할 일은 '기본'으로 이관 (UC-06 AC-02, AC-03)
- '기본' 카테고리 삭제 시도 시 즉시 오류 메시지 표시 (UC-06 AC-01, US-21)
- 할 일 카드 클릭 시 WF-04 수정 모달 열기 (UC-08) — 연필 버튼 제거, 카드 전체가 클릭 영역
- [삭제] 버튼 클릭 시 확인 절차 후 삭제 (UC-09 AC-02)
- [+ 할 일 추가] FAB 클릭 시 WF-04 모달 열기 (UC-07)
- 목록/캘린더 전환 버튼 클릭 시 뷰 전환, 캘린더 뷰에서는 월/주 토글 버튼 추가 표시 (UC-15 AC-01, AC-02)

#### 주요 인터랙션
